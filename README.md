# WebStudio

Навчальний проєкт WebStudio за макетом Figma. Сторінка містить секції Hero, Features, Team, Portfolio та Footer.

## Структура проєкту

```text
├── css/
│   ├── common.css
│   ├── features.css
│   ├── footer.css
│   ├── header.css
│   ├── hero.css
│   ├── main.css
│   ├── portfolio.css
│   └── team.css
├── images/
├── index.html
└── README.md
```

## Використані технології

- HTML5
- CSS3
- Google Fonts: Roboto та Raleway
- Modern Normalize через CDN

## Запуск

Відкрийте файл `index.html` у браузері. Стилі підключені через `css/main.css`, а зображення зберігаються в папці `images`.
